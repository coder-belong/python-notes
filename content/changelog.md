## v0.3.0 · 2026-11-12

有了账号：家里和公司登录同一个账号，学习进度是同一份。

- 【新功能】**登录注册**：注册完直接登录；学习时长、「学完了」、番茄数每分钟同步到账号上
- 【新功能】**侧栏收起**：点标题左边的图标或按 `\`，侧栏收成一条窄边，正文更宽
- 【新功能】**更新日志**：就是这里，有新版本时「⋯」上会出现小红点
- 【改进】**学习统计弹窗**：加宽，四张数字卡片，一整年热力图，新增「最长连续天数」
- 【改进】**登录弹窗**：滑动切换登录 / 注册、显示密码、输入时实时提示
- 【改进】**立即同步**：点了有反馈，同步中转圈，成功变绿，失败写明原因
- 【改进】**侧栏顶部**：字号、账号、主题收成一行图标，目录能多显示几节
- 【改进】**节号**：改成按阶段编号（1.1、2.5、3.9），以后插新节不用整篇重排

## v0.2.0 · 2026-11-11

笔记按 7 个阶段重新组织，阶段二全部写完；页面改成一次看一节。

- 【笔记】**阶段二补全**：依赖管理（uv / pyproject）、调试（看懂报错、pdb）、用 httpx 发请求、线程 / 进程 / 协程和 GIL
- 【笔记】**新增三节**：迭代器 / 生成器 / 装饰器、继承和多态、类型注解；async 补上超时和取消
- 【笔记】**学习路线**：补全到 7 个阶段，不太重点的标了「次要」
- 【新功能】**学习热力图**：像 GitHub 那样，一格一天，颜色越深学得越久
- 【新功能】**专注模式**：按 F 进入，侧栏收起，底部 25 分钟番茄钟，到点响铃
- 【新功能】**深色模式和字号**：一键切换浅色 / 深色，正文字号四档可调
- 【改进】**一次看一节**：首页放学习路线和「继续学习」，侧栏可以拖宽
- 【改进】**学习记录不丢**：每节有固定 id，以后改标题、调顺序都不影响进度
